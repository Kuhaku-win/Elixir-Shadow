> *“凌晨两点，代码修完了，Bug 全清了，你想喝一杯……”*

## ✨ 核心黑科技玩法 (Features)

### 1. 🍹 125 款大师精选酒谱库
- **权威收录**：覆盖 IBA 国际官方认证经典（日久弥新 / 当代经典 / 新时代）、世界大赛冠军作品（Bacardi Legacy / World Class）。
- **接地气特调**：不仅有硬核马天尼，还有雪碧、纯苹果汁、白葡萄汁、水蜜桃汁等**家庭高频夏日神仙特调**！
- **拼音简拼搜索**：键盘输入 `mtn` 秒出马天尼，输入 `mgl` 直达玛格丽特。

### 2. 🪄 智能平替与 3D 藏酒柜 (My Bar)
- **点亮库存**：在拟物化实木酒架上点亮你拥有的原料。
- **3 级平替推演**：缺君度？系统自动推荐用白橙皮酒或糖浆替代；缺青柠？自动换算黄柠檬酸度！
- **边际收益补料榜 (Top Restock ROI)**：告诉你**买哪一瓶新原料能解锁最多款新酒**，一键复制采购备忘录！

### 3. 🧪 赛博特调工坊 (Mixology Lab)
- **风味六芒星雷达**：实时量化酸、甜、苦、烈、果香、草本风味。
- **融冰稀释物理演化**：摇荡 12 秒融冰多少？搅拌 30 秒酒精度下降多少？算法全给你算好了！
- **吧台大字模式 (Bar Mode)**：做酒时手机放远点，超大字号分步倒计时，再也不怕酒液洒屏幕上。

### 4. 📜 派对酒单海报生成器 (Party Menu Maker)
- **2x 视网膜高清输出**：基于 Canvas 算法自绘 Q 版流光酒杯，一键导出印刷级 PNG 长图。
- **4 大主题排版**：暗夜黑金、复古羊皮纸、翡翠夜宴、赛博霓虹，轰趴发朋友圈直接出圈！
- **客用点单模式**：手机扫码即时翻阅你的私人客用酒单。

### 5. 🎨 5 套美学设计主题工坊
- 键盘轻敲字母 **`T`** 键，即可在【暗夜黑金】、【古典羊皮】、【翡翠夜宴】、【赛博霓虹】与【樱花特调】之间无缝切换，持久化零闪烁！

### 6. 🧮 毫升 / 盎司一键换算与份数缩放
- 支持 `ml ↔ oz` 毫秒级无损切换。1 人独酌、2 人浪漫、8 人狂欢，份数一拉配方自动等比缩放！

## 🏗️ 架构与极客技术栈 (Tech Stack)

```
       [ 用户浏览器 / 移动端 PWA ]
                  │
        (极致秒开 / 0 运行时依赖)
                  │
    ┌─────────────┴─────────────┐

[ Astro v5 (SSG) ]      [ React 18 (Islands) ]

  • 全站自动生成 Sitemap   • 全局 ⌘K 混合搜索引擎
    │                           │
    └─────────────┬─────────────┘
                  ▼
      [ Tailwind + Lucide Icons ]
      • 5 套深色美学动态主题
```

- **核心架构**：Astro v5 (纯静态生成 SSG)

- **UI 样式**：Tailwind CSS + Lucide Icons
- **测试框架**：Vitest（8 个测试套件，49 项测试 66ms 全通）
- **数据合规**：Zod Schema 运行时双向外键校验

## 🚀 3 秒极速开饮指南 (Quick Start)

### 1. 克隆并安装依赖
```bash
git clone https://github.com/Kuhaku-win/Elixir-Shadow.git
cd Elixir-Shadow
npm install
```

### 2. 启动本地吧台
```bash
npm run dev
```
浏览器打开 `http://localhost:4321`，今夜的调酒师就是你！🍸

### 3. 执行测试与生产构建
```bash
# 运行 49 项自动化测试
npm test

# 校验数据库外键约束
npm run verify-data

# 编译 242 个全静态生产页面
npm run build
```
